Your channels, beautifully organized.

IPTVo takes that messy provider playlist and turns it into a clean, deduplicated TV guide for Stremio and Nuvio — without the clutter, without the tracking, with your credentials encrypted at rest.

Yours, encrypted

Provider credentials are encrypted at rest using AES-256-GCM, and account passwords are hashed using PBKDF2 — they're never stored in plain text, and we never log them.

Calm, not cluttered

Reference matching against a guide of thousands of channels, AI dedup powered by OpenRouter — only if you switch it on.

On every screen

Install once in Stremio, Nuvio, or any addon-compatible app. One link, everywhere, with your channels the way you chose them.

Privacy, spelled out.

  • Your config is encrypted at rest with AES-256-GCM using a unique key per account.
  • If you enable AI curation, only channel names are sent to OpenRouter via your server, using your own key.
  • This is self-hosted and open source. Whoever runs the server is the only one who ever sees the data — that's the point.
